# Моя библиотека

Статический сайт: HTML, CSS и JavaScript без сборки. Книги хранятся в файле `books.json`.

## Структура

```
index.html        главная страница
css/style.css     оформление
js/app.js         логика (полка, оглавление, чтение)
books.json        ваши книги и главы
```

## Как добавлять книги

Откройте `books.json` и добавьте объект в список `books`:

```json
{
  "id": "moya-kniga",
  "title": "Название книги",
  "author": "Ваше имя",
  "desc": "Короткое описание.",
  "color": "#6b4324",
  "chapters": [
    { "title": "Первая глава", "text": "Первый абзац.\n\nВторой абзац." }
  ]
}
```

- `id` — латиницей, без пробелов, уникальный. Попадает в адрес страницы.
- `color` — цвет корешка на полке (необязательно). Например `#7a3e22`.
- В `text` абзацы разделяются пустой строкой: `\n\n`.
- Кавычки внутри текста экранируйте обратным слешем: `\"`.

Проверьте, что файл остался корректным JSON (запятые между объектами, без лишней запятой в конце).

## Как посмотреть локально

Браузер не даёт читать `books.json` при открытии файла двойным щелчком, нужен простой сервер. Например, из папки проекта:

```
python3 -m http.server 8000
```

И откройте в браузере http://localhost:8000

## Как выложить на GitHub Pages

1. Создайте репозиторий на github.com, например `my-library`. Можно публичный.
2. В папке проекта выполните:

```
git init
git add .
git commit -m "Первая версия библиотеки"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/my-library.git
git push -u origin main
```

3. На GitHub откройте репозиторий: **Settings → Pages**.
4. В разделе **Build and deployment** выберите Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**, и нажмите Save.
5. Через минуту сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/my-library/`.

Чтобы обновить сайт после изменений:

```
git add .
git commit -m "Новая глава"
git push
```

## Важно

На GitHub Pages нет сервера, поэтому книги нельзя редактировать прямо в браузере, как в предыдущей версии с базой данных. Вы правите `books.json` на компьютере и публикуете изменения через git. Если захотите писать с телефона, можно позже добавить простую форму, которая формирует этот же JSON.
